# Splunk Tools

A collection of Splunk SPL searches, detections, and threat-hunting references for security monitoring and investigations. Maintained by [@EvolvingSysadmin](https://github.com/EvolvingSysadmin).

Read it at [splunk.ryanheavican.com](https://splunk.ryanheavican.com) or browse the Markdown in [docs/](docs/index.md). Companion to the [Blue Team Toolkit](https://blueteam.ryanheavican.com).

## Build locally

```
pip install -r requirements.txt
mkdocs serve
```

Then open <http://127.0.0.1:8000>.
